Iconography

Custom icon set exported from the Figma Iconography library into a self-contained sprite (icons.svg). Reference with <svg class="icon"><use href="#i-{slug}"></svg> — sized in em, coloured via currentColor.

Pictograms

Detailed 64×64 line-art illustrations for empty, error, success and info states — a richer counterpart to Iconography. Blue line-art over soft fills; recolour via the color property or add .is-muted. Reference with <span class="pictogram"><svg>…</svg></span>.

Sheet

Editable spreadsheet variant of the table — grid lines, sticky header + # gutter, and every cell editable through one shared state machine. Same <table class="table"> base as the wide variant, so a prototype can toggle .table-wide ⇄ .table-sheet. Six cell primitives: text (Name/Description), single-select (Status/Health), person, date (+ roadmap dot / RoB time), multi-select tags, link.

Control strip above a table or list — search, filters, quick-filter selects, and a view switcher. Composes existing parts: .input-icon search, .input-select, .btn, .segmented, .checkbox. Left cluster grows; .toolbar-end pins controls right.

Tooltips

CSS-only tooltip on any element via data-tooltip="…". Default placement is top; override with data-placement="bottom", left, or right. Two styles: compact (default, dark pill for short labels) and regular (data-tooltip-style="regular" — white surface, wrapping body text, caret). Reveals on hover and keyboard focus.
