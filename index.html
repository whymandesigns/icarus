Plugin — Review bar →

Built into every prototype — comment on elements, retype copy in place, spotlight a region. Turn it on with the circle button bottom-right or ?review=1; comments land in feedback.json for an agent to apply.

Plugin — States switcher →

A floating panel bottom-left that jumps between a prototype's designed states (empty, loading, error, each flow step). Open with ?states=1, deep-link with &state=<key>. Copied into each prototype by hand; this page has the snippet.

Plugin — Component map →

Goggles for the component kit: outlines every component that has a React counterpart and shows its Picasso import, live JSX and Storybook link on hover. Open the kit with ?map=1. Reads figma-map.json; kit-only for now.
